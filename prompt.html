Supabase 스키마 프롬프트

Supabase(PostgreSQL)용 SQL 스키마를 작성해줘. 제주 특산품 쇼핑몰 + 방명록 앱이야.
SQL Editor에 그대로 붙여넣어 실행할 수 있게 한 파일로 만들어줘.

## 테이블

1. products (상품)
   - id: bigint identity PK
   - name: text, 필수
   - description: text
   - emoji: text
   - price: integer, 필수, 0보다 커야 함
   - created_at: timestamptz, 기본값 now()

2. cart_items (장바구니)
   - id: bigint identity PK
   - user_id: uuid, 필수, 기본값 auth.uid(), auth.users 참조, 유저 삭제 시 함께 삭제
   - product_id: bigint, 필수, products 참조, 상품 삭제 시 함께 삭제
   - quantity: integer, 필수, 기본값 1, 0보다 커야 함
   - (user_id, product_id) 조합은 유일해야 함

3. orders (주문)
   - id: bigint identity PK
   - user_id: uuid, 필수, 기본값 auth.uid(), auth.users 참조, 유저 삭제 시 함께 삭제
   - product_id: bigint, products 참조, 상품 삭제 시 null로 설정
   - product_name: text, 필수 (주문 시점 상품명 스냅샷)
   - unit_price: integer, 필수
   - quantity: integer, 필수, 0보다 커야 함
   - total_price: integer, unit_price * quantity로 DB가 자동 계산 (generated stored column)
   - status: text, 필수, 기본값 'ordered', 'ordered' 또는 'returned'만 허용
   - created_at: timestamptz, 기본값 now()

4. guestbook_posts (방명록 글)
   - id: bigint identity PK
   - user_id: uuid, 필수, 기본값 auth.uid(), auth.users 참조, 유저 삭제 시 함께 삭제
   - author: text, 필수
   - content: text, 필수
   - created_at: timestamptz, 기본값 now()

5. guestbook_comments (댓글)
   - id: bigint identity PK
   - post_id: bigint, 필수, guestbook_posts 참조, 글 삭제 시 함께 삭제
   - user_id: uuid, 필수, 기본값 auth.uid(), auth.users 참조, 유저 삭제 시 함께 삭제
   - author: text, 필수
   - content: text, 필수
   - created_at: timestamptz, 기본값 now()

6. guestbook_likes (좋아요)
   - post_id: bigint, 필수, guestbook_posts 참조, 글 삭제 시 함께 삭제
   - user_id: uuid, 필수, 기본값 auth.uid(), auth.users 참조, 유저 삭제 시 함께 삭제
   - (post_id, user_id)가 복합 PK (한 유저는 글당 좋아요 1회)

모든 테이블은 create table if not exists로 만들어줘.

## RLS (행 단위 보안)
6개 테이블 모두 RLS를 활성화하고 아래 정책을 만들어줘.

- products: 누구나 조회만 가능
- cart_items, orders: 본인 행(auth.uid() = user_id)만 모든 작업 가능 (using + with check 둘 다)
- guestbook_posts, guestbook_comments, guestbook_likes:
  - 조회: 누구나
  - 작성: 본인 user_id로만
  - 삭제: 본인 행만
  - 수정 정책은 만들지 않음
